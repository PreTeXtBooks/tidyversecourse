# Animated GIFs (gganimate output)

These GIFs are the animated versions of the static PNGs `images/dataviz-unnamed-chunk-88-1.png` ... `-99-1.png`.

They live outside `assets/images/` on purpose: PreTeXt substitutes a same-named `.gif` for a `.png` when one sits alongside it, and LaTeX cannot embed GIFs ("Cannot determine size of graphic ... no BoundingBox"), which breaks the PDF build.
